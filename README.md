# พี่หนูพาตะลุยหมู่เกาะความรู้ 🐭✈️

เกมเรียนรู้ STEM ภาษาไทยสำหรับเด็ก 5–6 ขวบ มีเสียงพากย์ทุกประโยค เล่นบนเว็บเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง

- 9 เกาะ 33 ด่าน: วิทยาศาสตร์ เทคโนโลยี (เขียนโค้ดหุ่นยนต์) วิศวกรรม คณิตศาสตร์ อวกาศ ทะเล ร่างกาย ครัวนักวิทย์ และเกาะหัวใจ (มารยาทและความมีน้ำใจ)
- แทรกเรื่องความดีในทุกเกาะ ทำความดีได้เหรียญ ใช้แต่งห้องนอน
- รองรับหลายผู้เล่นในเครื่องเดียว แต่ละคนมีดาว สติกเกอร์ และหน้าสรุปสำหรับผู้ปกครองแยกกัน
- ผลการเล่นเก็บไว้ในเบราว์เซอร์ของเครื่องที่เล่นเท่านั้น ไม่ส่งข้อมูลไปที่ไหน

แนะนำให้เล่นบนคอมพิวเตอร์หรือแท็บเล็ตจอแนวนอน
